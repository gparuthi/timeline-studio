How to write a timeline

One event per line. Use 24-hour times or AM/PM. Only a time and title are required. A span is 15:00 - 17:00 or 15:00 +2h. 

08:00 | Coffee and pastries
09:30 | Observatory | Hike up | pin | sky
1:00 PM | Museum | Gardens first | ticket | sand
3:00 - 5:00 PM | Playground | | palm | sage

Fields: time | title | description | icon | color. Leave an empty field to skip it. Write \| inside text for a literal pipe.

Icons: home, plane, depart, land, coffee, ticket, pin, car, road, palm. Colors: sky, sand, sage. 

title: My Trip
date: Saturday, Jun 6, 2026
subtitle: A day to remember
range: 08:00 - 16:00
theme: travel
note: Remember your ID
footer: See you there ♡

The range uses whole hours within one day; omit it to fit the events automatically. theme: picks a look (travel, minimal, retro, future, code); the toolbar picker writes this line for you. For several days, start each one with day: Sun, Sep 20; events, range: and note: lines below it belong to that day. Events sort by time, preserving the order of simultaneous events. Lines beginning with # are comments.

Add your own images

Name an image, then choose a file. It becomes an embedded asset in your text, so it travels with saved files.

Use @hotel instead of an icon, or header-art: @hotel for header artwork. 

16:00 | Check in | Ocean view | @hotel | sage

Image URLs also work:

asset hotel: https://example.com/hotel.png

Uploaded images work offline. Linked images need a network connection.

Save studio keeps the editor, your timeline, and uploaded images together in one HTML file.
