How to write a timeline

One event per line. Use 24-hour times or AM/PM. Only a time and title are required. A span is 15:00 - 17:00 or 15:00 +2h. 

08:00 | Coffee and pastries
09:30 | Observatory | Hike up | pin | sky
1:00 PM | Museum | Gardens first | ticket | sand
3:00 - 5:00 PM | Playground | | palm | sage

Fields: time | title | description | icon | color | picture. Leave an empty field to skip it. Write \| inside text for a literal pipe.

Icons: home, plane, depart, land, coffee, meal, tree, bed, shop, ticket, pin, car, road, palm, dumbbell, run, stretch, timer, pot. Leave the icon empty and it is guessed from the words (lunch → meal, park → tree, flight lands → land, plank → dumbbell, rest → timer, boil → pot). Colors: sky, sand, sage. Links in a description or note are clickable; a map link becomes a pin chip, and a pasted maps.app.goo.gl link gets the place name and address filled in before it. Add link: my-week and tl.gaup.uk/my-week follows your edits; the studio appends an edit id to that line on the first publish, and any device whose text has the id can update the name. 

title: My Trip
date: Saturday, Jun 6, 2026
subtitle: A day to remember
range: 08:00 - 16:00
theme: travel
note: Remember your ID
footer: See you there ♡

The range uses whole hours within one day; omit it to fit the events automatically. theme: picks a look (travel, minimal, retro, future, code); the toolbar picker writes this line for you. For several days, start each one with day: Sun, Sep 20; events, range: and note: lines below it belong to that day. Events sort by time, preserving the order of simultaneous events. Lines beginning with # are comments.

Workouts and recipes

Start the first step with its length and the text is a routine, run from a Start button instead of the clock: +45s | Plank is a 45-second step after the line above it, 15:00 +25m a step at a fixed time, and steps may overlap (they sit side by side). - lines under a step are its notes, and note: lines become things to tick off. A running routine shows the step, a countdown and the next step, with Beeps and Announce steps switches. On a saved link every device with it open follows the same run: start on the phone, watch on the TV. New ▾ has a workout and a recipe to start from. 

title: 5-min Core
+30s | Jog in place
+45s | Plank | Elbows under shoulders
- Hips level
+15s | Rest

Tap a step's card, then Photo, to give it a picture; tap the title for a cover photo.

Change it in plain words

The box above the text takes an instruction: move golf to 3 pm, add dinner with Sam on Friday at 7, push everything on Monday back an hour, and in a routine make rests 20s or roast 5 minutes longer. The text and the instruction go to the link server, which asks a model for the edited text; it is applied only if it still reads as a timeline, the cursor lands on the first changed line, and the toast offers Undo. Times without AM/PM follow the event (dinner at 7:30 is 19:30). This sends the timeline off your device like a short link does.

Write one with ChatGPT or Claude

Add Timeline Studio as a connector once and a chat can make, save and change timelines itself (make me a recipe timeline for sheet-pan chicken) and hands you the link. No sign-in.

https://tl.gaup.uk/mcp

ChatGPT (web): Settings → Apps & Connectors → Advanced settings → Developer mode on, then Create: paste the address, Authentication No authentication. In a chat, pick it from + → Developer mode. Claude: Settings → Connectors → Add custom connector, paste the address; turn it on in a chat from the tools menu.

Without the connector, any AI chat can still write one. Start your message with Read https://tl.gaup.uk/llms.txt and make me a timeline: and describe the day or trip. It answers with a link that opens the timeline here, and the text to paste into the editor if the link does not work. The instructions it reads: tl.gaup.uk/llms.txt.

Add your own images

For a step's photo, tap its card and then Photo beside the highlighted line; tap the title for a Cover photo. Or name an image here and choose a file. On tl.gaup.uk a photo is shrunk and uploaded, and the text gets its short link; in a standalone copy it is embedded in the text.

Use @hotel as a picture (the 6th field), instead of an icon, as cover: @hotel above the title, or header-art: @hotel for header artwork. 

16:00 | Check in | Ocean view | | sage | @hotel

Image URLs also work:

asset hotel: https://example.com/hotel.png

Embedded images work offline. Linked and uploaded images need a network connection.

Save studio keeps the editor, your timeline, and uploaded images together in one HTML file.
